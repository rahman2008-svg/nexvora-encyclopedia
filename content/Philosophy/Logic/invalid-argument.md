# অবৈধ যুক্তি বা Invalid Argument

## সংক্ষিপ্ত পরিচিতি

Invalid Argument বা অবৈধ যুক্তি হলো এমন একটি Deductive Argument যার Premise-গুলো সত্য হলেও Conclusion মিথ্যা হওয়ার যৌক্তিক সম্ভাবনা থাকে।

অন্যভাবে বলা যায়, কোনো Argument Invalid হলে এমন একটি সম্ভাব্য পরিস্থিতি কল্পনা করা যায় যেখানে Argument-এর সব Premise সত্য কিন্তু Conclusion মিথ্যা।

এটি Validity-এর বিপরীত ধারণা।

উদাহরণ:

যদি বৃষ্টি হয়, তাহলে রাস্তা ভিজবে।  
রাস্তা ভেজা।  
অতএব, বৃষ্টি হয়েছে।

এখানে:

P → Q  
Q  
∴ P

এই Logical Form Valid নয়। কারণ রাস্তা অন্য কারণেও ভেজা হতে পারে।

তাই এটি একটি Invalid Argument।

## Invalid Argument-এর ধারণা

যুক্তিবিদ্যায় Argument-এর প্রধান দুটি অংশ হলো:

- Premise
- Conclusion

Premise থেকে Conclusion যৌক্তিকভাবে অনুসরণ করলে Argument Valid হতে পারে।

কিন্তু যদি Premise সত্য হওয়া সত্ত্বেও Conclusion মিথ্যা হতে পারে, তাহলে Argument Invalid।

সহজভাবে:

**Valid Argument:**  
Premise সত্য → Conclusion মিথ্যা হতে পারে না।

**Invalid Argument:**  
Premise সত্য → Conclusion মিথ্যা হওয়ার সম্ভাবনা আছে।

---

## Invalid Argument-এর সংজ্ঞা

একটি Deductive Argument Invalid যদি এমন অন্তত একটি Logical Possibility থাকে যেখানে:

- Argument-এর সব Premise সত্য
- কিন্তু Conclusion মিথ্যা

এই পরিস্থিতিকে Argument-এর Countermodel বা Counterexample দ্বারা প্রদর্শন করা যেতে পারে।

Formalভাবে:

যদি কোনো Interpretation-এ:

P₁, P₂, ..., Pₙ সত্য

কিন্তু:

C মিথ্যা

হয়, তাহলে:

P₁, P₂, ..., Pₙ ⊭ C

অর্থাৎ Premises Conclusion-কে Logically Entail করে না।

## Valid ও Invalid Argument

### Valid Argument

Valid Argument-এর ক্ষেত্রে এমন কোনো সম্ভাব্য পরিস্থিতি নেই যেখানে সব Premise সত্য এবং Conclusion মিথ্যা।

### Invalid Argument

Invalid Argument-এর ক্ষেত্রে অন্তত একটি এমন সম্ভাব্য পরিস্থিতি রয়েছে যেখানে সব Premise সত্য কিন্তু Conclusion মিথ্যা।

---

## Invalidity কীভাবে নির্ধারণ করা হয়

Invalid Argument শনাক্ত করার প্রধান পদ্ধতিগুলো হলো:

1. Logical Form বিশ্লেষণ
2. Truth Table
3. Counterexample
4. Countermodel
5. Formal Proof Techniques
6. Predicate বা Categorical Structure বিশ্লেষণ

---

## Counterexample

Counterexample হলো এমন একটি উদাহরণ যা দেখায় যে কোনো Argument-এর Premise সত্য হলেও Conclusion মিথ্যা হতে পারে।

উদাহরণ:

যদি বৃষ্টি হয়, রাস্তা ভিজবে।  
রাস্তা ভেজা।  
অতএব, বৃষ্টি হয়েছে।

ধরা যাক রাস্তা ভেজার কারণ ছিল রাস্তা পরিষ্কার করার জন্য পানি দেওয়া।

তাহলে:

- যদি বৃষ্টি হয় → রাস্তা ভেজে — সত্য
- রাস্তা ভেজা — সত্য
- বৃষ্টি হয়েছে — মিথ্যা

অতএব, Argument Invalid।

---

## Premise সত্য কিন্তু Argument Invalid

একটি গুরুত্বপূর্ণ বিষয় হলো:

**সত্য Premise থাকলেই Argument Valid হয় না।**

উদাহরণ:

ঢাকা বাংলাদেশের রাজধানী।  
পৃথিবী সূর্যের চারদিকে ঘোরে।  
অতএব, ২ + ২ = ৪।

এখানে তিনটি বক্তব্যই সত্য হতে পারে।

কিন্তু প্রথম দুটি Premise থেকে Conclusion যৌক্তিকভাবে অনুসরণ করে না।

তাই Argument Invalid।

---

## Conclusion সত্য হলেও Argument Invalid

Conclusion সত্য হলেও Argument Valid হওয়া আবশ্যক নয়।

উদাহরণ:

বাংলাদেশ একটি দেশ।  
চাঁদ পৃথিবীর উপগ্রহ।  
অতএব, ২ + ২ = ৪।

Conclusion সত্য।

কিন্তু Premise থেকে Conclusion যৌক্তিকভাবে অনুসরণ করছে না।

তাই Argument Invalid।

এটি দেখায়:

**True Conclusion ≠ Valid Argument**

---

## False Premise ও Invalid Argument

Invalid Argument-এর Premise সত্য হতে হবে এমন কোনো শর্ত নেই।

একটি Argument একই সঙ্গে:

- False Premise
- Invalid Logical Form

দুটিই ধারণ করতে পারে।

উদাহরণ:

সকল বিড়াল উড়তে পারে।  
সব উড়তে সক্ষম প্রাণী পাখি।  
অতএব, সব বিড়াল পাখি।

এখানে Premise-গুলোর সত্যতা নিয়ে সমস্যা রয়েছে এবং Argument-এর Logical Structure-ও যথাযথভাবে Conclusion প্রতিষ্ঠা করে না।

---

## Invalid Argument ও Soundness

Sound Argument অবশ্যই Valid হতে হবে।

তাই:

**Invalid Argument → Unsound**

কোনো Invalid Argument কখনো Sound হতে পারে না।

তবে:

**Unsound Argument → অবশ্যই Invalid নয়।**

কারণ একটি Argument Valid হতে পারে কিন্তু False Premise থাকার কারণে Unsound হতে পারে।

---

## Invalid Argument ও Unsoundness

Soundness-এর দুটি শর্ত:

1. Validity
2. True Premises

Invalid Argument প্রথম শর্তেই ব্যর্থ।

তাই কোনো Argument Invalid হলে সেটি অবশ্যই Unsound।

---

## Formal Logical Structure

ধরা যাক:

P = বৃষ্টি হচ্ছে।

Q = রাস্তা ভেজা।

Argument:

P → Q  
Q  
∴ P

এই Argument-এর Logical Form:

**If P then Q.  
Q.  
Therefore P.**

এটি Valid Form নয়।

কারণ Q সত্য হওয়ার অন্য কারণ থাকতে পারে।

এই Fallacy-কে বলা হয়:

**Affirming the Consequent**

---

## Truth Table-এর মাধ্যমে Invalidity

ধরা যাক:

P → Q  
Q  
∴ P

একটি সম্ভাব্য Truth Assignment:

P = False  
Q = True

তাহলে:

P → Q = True  
Q = True  
P = False

অর্থাৎ:

Premise 1 = True  
Premise 2 = True  
Conclusion = False

এমন একটি Row পাওয়া গেলেই Argument Invalid প্রমাণিত হয়।

---

## Common Invalid Argument Forms

কিছু প্রচলিত Invalid Argument Form হলো:

- Affirming the Consequent
- Denying the Antecedent
- Converse Error
- Inverse Error
- Undistributed Middle
- Non Sequitur
- False Dilemma
- Hasty Generalization
- অন্যান্য Logical Fallacy

তবে সব Logical Fallacy একই ধরনের Formal Invalidity নয়। কিছু Fallacy Argument-এর Content, Relevance বা Informal Reasoning-এর সমস্যার সঙ্গে সম্পর্কিত।

---

## Affirming the Consequent

গঠন:

P → Q  
Q  
∴ P

উদাহরণ:

যদি আগুন লাগে, ধোঁয়া দেখা যাবে।  
ধোঁয়া দেখা যাচ্ছে।  
অতএব, আগুন লেগেছে।

এটি Invalid হতে পারে, কারণ ধোঁয়ার অন্য উৎস থাকতে পারে।

---

## Denying the Antecedent

গঠন:

P → Q  
¬P  
∴ ¬Q

উদাহরণ:

যদি বৃষ্টি হয়, রাস্তা ভিজবে।  
বৃষ্টি হচ্ছে না।  
অতএব, রাস্তা ভেজা নয়।

এটি Invalid, কারণ রাস্তা অন্য কোনো কারণে ভেজা থাকতে পারে।

---

## Undistributed Middle

Categorical Syllogism-এ Middle Term যথাযথভাবে Distributed না হলে Invalidity দেখা দিতে পারে।

উদাহরণ:

সব বিড়াল প্রাণী।  
সব কুকুর প্রাণী।  
অতএব, সব কুকুর বিড়াল।

এখানে "প্রাণী" হওয়ার বৈশিষ্ট্য থেকে কুকুর ও বিড়ালের মধ্যে সমতা প্রতিষ্ঠিত হয় না।

তাই Argument Invalid।

---

## Converse Error

কোনো Conditional Statement-এর Converse-কে মূল Statement-এর সমতুল্য ধরে নিলে Error হতে পারে।

যেমন:

P → Q

থেকে:

Q → P

সরাসরি অনুসরণ করে না।

উদাহরণ:

যদি কোনো প্রাণী কুকুর হয়, তাহলে সেটি প্রাণী।

কিন্তু কোনো প্রাণী হলেই সেটি কুকুর নয়।

---

## Inverse Error

P → Q থেকে:

¬P → ¬Q

সরাসরি অনুসরণ করে না।

উদাহরণ:

যদি কোনো সংখ্যা ৪-এর গুণিতক হয়, তাহলে তা জোড়।

কিন্তু কোনো সংখ্যা ৪-এর গুণিতক না হলেই তা বিজোড় নয়।

যেমন ৬ হলো ৪-এর গুণিতক নয়, কিন্তু ৬ জোড়।

---

## Non Sequitur

Non Sequitur হলো এমন একটি Argument যেখানে Conclusion Premise থেকে যথাযথভাবে অনুসরণ করে না।

উদাহরণ:

আজ আকাশ পরিষ্কার।  
রহিম একজন ছাত্র।  
অতএব, ২ + ২ = ৪।

এখানে Premise ও Conclusion-এর মধ্যে Logical Connection নেই।

---

## Invalid Categorical Argument

Categorical Argument-এ Subject, Predicate এবং Middle Term-এর সম্পর্ক সঠিকভাবে প্রতিষ্ঠিত না হলে Argument Invalid হতে পারে।

উদাহরণ:

সব ডাক্তার শিক্ষিত।  
সব শিক্ষক শিক্ষিত।  
অতএব, সব শিক্ষক ডাক্তার।

এখানে উভয় শ্রেণির সদস্য একই বৈশিষ্ট্য ধারণ করলেও তারা একই শ্রেণি নয়।

---

## Invalid Conditional Argument

Conditional Argument-এ ভুল Logical Inference Invalidity সৃষ্টি করতে পারে।

উদাহরণ:

যদি P হয়, তাহলে Q হবে।  
Q হয়েছে।  
অতএব, P হয়েছে।

এটি Affirming the Consequent।

---

## Invalid Argument ও Logical Fallacy

অনেক Logical Fallacy Argument-এর Reasoning Structure দুর্বল বা ভুল করে।

যেমন:

- Affirming the Consequent
- Denying the Antecedent
- False Dilemma
- Hasty Generalization
- Appeal to Irrelevant Authority
- Circular Reasoning

তবে Formal Logic-এর Invalid Argument এবং Informal Fallacy সব ক্ষেত্রে একই বিষয় নয়।

---

## Invalid Argument ও Deductive Reasoning

Deductive Reasoning-এ Conclusion Premise থেকে Necessaryভাবে অনুসরণ করার কথা।

যদি তা না হয়, Argument Invalid।

Deductive Argument-এর ক্ষেত্রে Invalidity বিশেষভাবে গুরুত্বপূর্ণ কারণ এটি Logical Necessity ব্যর্থ হওয়া নির্দেশ করে।

---

## Invalid Argument ও Inductive Reasoning

Inductive Argument সাধারণত Valid বা Invalid-এর পরিবর্তে:

- Strong
- Weak
- Cogent
- Uncogent

ইত্যাদি ধারণার মাধ্যমে মূল্যায়ন করা হয়।

তাই "Invalid Argument" শব্দটি সাধারণত Deductive Argument-এর ক্ষেত্রে বেশি ব্যবহৃত হয়।

---

## Invalid Argument ও Propositional Logic

Propositional Logic-এ Truth Table ব্যবহার করে Invalidity পরীক্ষা করা যায়।

যদি এমন একটি Row পাওয়া যায় যেখানে:

সব Premise = True

এবং:

Conclusion = False

তাহলে Argument Invalid।

---

## Invalid Argument ও Predicate Logic

Predicate Logic-এও Countermodel ব্যবহার করে Invalidity দেখানো যায়।

যদি এমন একটি Interpretation পাওয়া যায় যেখানে:

- সব Premise True
- Conclusion False

তাহলে Argument Valid নয়।

---

## Invalid Argument ও Mathematical Logic

Mathematical Logic-এ Invalidity গুরুত্বপূর্ণ কারণ এটি দেখায় যে কোনো Conclusion প্রদত্ত Premise থেকে Logicalভাবে অনুসরণ করছে না।

Formal Proof এবং Semantic Analysis-এর মাধ্যমে এই বিষয়টি পরীক্ষা করা যায়।

## Invalid Argument ও Computer Science

Computer Science-এ Logical Validity গুরুত্বপূর্ণ:

- Formal Verification
- Program Verification
- Model Checking
- Automated Reasoning
- SAT/SMT Solving
- Database Query Logic
- Knowledge Representation

ইত্যাদিতে।

ভুল Logical Inference কোনো Software System-এর Incorrect Result তৈরি করতে পারে।

## Invalid Argument ও Programming

Programming-এ Conditional এবং Boolean Expression ব্যবহারের সময় ভুল Logical Reasoning সমস্যা তৈরি করতে পারে।

উদাহরণ:

```text
if A:
    ...
থেকে স্বয়ংক্রিয়ভাবে:
if B:
    A
ধরনের কোনো সিদ্ধান্ত নেওয়া Logicalভাবে সঠিক নয়, যদি A ও B-এর সম্পর্ক যথেষ্টভাবে প্রতিষ্ঠিত না থাকে।
Programming-এ:
AND
OR
NOT
IF
ELSE
Boolean Condition
ইত্যাদি ব্যবহারের ক্ষেত্রে Logical Structure বোঝা গুরুত্বপূর্ণ।
Invalid Argument ও Artificial Intelligence
AI Reasoning System-এ Invalid Inference ভুল Conclusion তৈরি করতে পারে।
Rule-based System-এ:
Fact + Rule → Conclusion
এই Inference যদি Rule অনুযায়ী না হয়, তাহলে Incorrect বা Invalid Reasoning হতে পারে।
Symbolic AI-তে Formal Logic ব্যবহার করে এসব সমস্যা শনাক্ত ও নিয়ন্ত্রণ করা যায়।
তবে Machine Learning Model-এর ভুল Prediction-কে সরাসরি Classical Invalid Argument হিসেবে গণ্য করা যায় না।
বাস্তব জীবনে Invalid Argument
দৈনন্দিন কথাবার্তায় Invalid Argument খুব সাধারণ।
উদাহরণ:
যদি কেউ ভালো ছাত্র হয়, তাহলে সে পরীক্ষায় ভালো করবে।
রহিম পরীক্ষায় ভালো করেছে।
অতএব, রহিম অবশ্যই ভালো ছাত্র।
এটি Valid নয়, কারণ পরীক্ষায় ভালো করার অন্য কারণ থাকতে পারে।
Invalid Argument শনাক্ত করার পদ্ধতি
ধাপ ১ — Premise শনাক্ত করুন
Argument-এর সব Premise আলাদা করুন।
ধাপ ২ — Conclusion শনাক্ত করুন
কোন বক্তব্যটি প্রতিষ্ঠা করার চেষ্টা করা হচ্ছে তা নির্ধারণ করুন।
ধাপ ৩ — Logical Form বের করুন
প্রয়োজনে P, Q, R ইত্যাদি Symbol ব্যবহার করুন।
ধাপ ৪ — Validity পরীক্ষা করুন
Truth Table বা Formal Reasoning ব্যবহার করুন।
ধাপ ৫ — Counterexample খুঁজুন
এমন একটি পরিস্থিতি খুঁজুন যেখানে:
Premises True
কিন্তু:
Conclusion False।
ধাপ ৬ — সিদ্ধান্ত নিন
Counterexample পাওয়া গেলে:
Argument Invalid।
Invalid Argument-এর উদাহরণ
উদাহরণ ১
যদি বৃষ্টি হয়, রাস্তা ভিজবে।
রাস্তা ভেজা।
অতএব, বৃষ্টি হয়েছে।
Result: Invalid
Fallacy: Affirming the Consequent
উদাহরণ ২
যদি বিদ্যুৎ থাকে, বাতি জ্বলবে।
বিদ্যুৎ নেই।
অতএব, বাতি জ্বলবে না।
এটি সব পরিস্থিতিতে Valid নয়, কারণ অন্য কোনো বিদ্যুৎ উৎস থাকতে পারে বা Conditional Statement-এর প্রয়োজনীয় শর্ত ভিন্ন হতে পারে।
উদাহরণ ৩
সব বিড়াল প্রাণী।
সব কুকুর প্রাণী।
অতএব, সব কুকুর বিড়াল।
Result: Invalid
কারণ "প্রাণী" হওয়া কুকুর ও বিড়ালের শ্রেণিকে এক করে না।
উদাহরণ ৪
সকল ডাক্তার শিক্ষিত।
রহিম শিক্ষিত।
অতএব, রহিম ডাক্তার।
Result: Invalid
কারণ অনেক অ-ডাক্তারও শিক্ষিত হতে পারেন।
Valid Argument-কে Invalid Argument থেকে আলাদা করা
একটি সহজ পরীক্ষার পদ্ধতি:
নিজেকে প্রশ্ন করুন:
"আমি কি এমন একটি পরিস্থিতি কল্পনা করতে পারি যেখানে সব Premise সত্য, কিন্তু Conclusion মিথ্যা?"
যদি উত্তর:
হ্যাঁ
তাহলে Argument Invalid।
যদি এমন কোনো পরিস্থিতি সম্ভব না হয়, তাহলে Argument Valid হতে পারে।

Invalid Argument মানেই তার Conclusion অবশ্যই মিথ্যা—এমন নয়।
এটি খুব গুরুত্বপূর্ণ।
একটি Invalid Argument-এর Conclusion:
সত্য হতে পারে

কিন্তু Conclusion-এর সত্যতা Premise থেকে Logicalভাবে নিশ্চিত হয় না।
অতএব:
Invalid ≠ False Conclusion
বরং:
Invalid = Premises do not logically guarantee the Conclusion

Invalid Argument বিশ্লেষণের সম্পূর্ণ উদাহরণ
Argument:
যদি বৃষ্টি হয়, রাস্তা ভিজবে।
রাস্তা ভেজা।
অতএব, বৃষ্টি হয়েছে।
Step 1 — Proposition নির্ধারণ
P = বৃষ্টি হচ্ছে।
Q = রাস্তা ভেজা।
Step 2 — Logical Form
P → Q
Q
∴ P
Step 3 — Validity পরীক্ষা
ধরা যাক:
P = False
Q = True
তাহলে:
P → Q = True
Q = True
কিন্তু:
P = False
অর্থাৎ:
Premise 1 = True
Premise 2 = True
Conclusion = False
Step 4 — Counterexample
রাস্তা বৃষ্টির কারণে নয়, অন্য কোনো কারণে ভিজে থাকতে পারে।
Step 5 — Final Result

Invalid
এবং এটি:
Affirming the Consequent
এর উদাহরণ।

উপসংহার
Invalid Argument বা অবৈধ যুক্তি হলো এমন একটি Deductive Argument যার Premise-গুলো সত্য হলেও Conclusion মিথ্যা হওয়ার সম্ভাবনা থাকে।
অর্থাৎ Premise-গুলো Conclusion-কে Logicalভাবে নিশ্চয়তা দেয় না।
Invalid Argument শনাক্ত করার সবচেয়ে গুরুত্বপূর্ণ পদ্ধতি হলো এমন একটি Counterexample খুঁজে বের করা যেখানে:
সব Premise সত্য কিন্তু Conclusion মিথ্যা।
যদি এমন পরিস্থিতি পাওয়া যায়, তাহলে Argument Invalid।
Validity এবং Soundness বোঝার ক্ষেত্রেও Invalid Argument অত্যন্ত গুরুত্বপূর্ণ। কারণ একটি Invalid Argument কখনো Sound হতে পারে না।
তবে Invalid Argument-এর Conclusion অবশ্যই মিথ্যা—এমন ধারণা ভুল। Conclusion সত্য হলেও Argument Invalid হতে পারে, যদি Conclusion Premise থেকে Logicalভাবে অনুসরণ না করে।
Propositional Logic, Predicate Logic, Mathematical Logic, Computer Science, Programming, Formal Verification এবং Artificial Intelligence-এর বিভিন্ন ক্ষেত্রে Invalid Inference শনাক্ত করা গুরুত্বপূর্ণ।
সঠিক Logical Reasoning গড়ে তুলতে শুধু Conclusion সঠিক কি না তা দেখা যথেষ্ট নয়; বরং Premise থেকে Conclusion কীভাবে এবং কোন Logical Rule-এর মাধ্যমে এসেছে সেটিও পরীক্ষা করতে হয়।
