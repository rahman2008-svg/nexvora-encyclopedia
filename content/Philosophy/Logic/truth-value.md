সত্যমূল্য

সংক্ষিপ্ত পরিচিতি

সত্যমূল্য (Truth Value) হলো কোনো Proposition বা বচন সত্য নাকি মিথ্যা—তা নির্দেশকারী মান। Classical Logic-এ সাধারণত দুটি Truth Value ব্যবহার করা হয়: সত্য (True) এবং মিথ্যা (False)।

উদাহরণ:

«বাংলাদেশ দক্ষিণ এশিয়ার একটি দেশ।»

এই Proposition-এর Truth Value হলো:

True

অন্যদিকে:

«বাংলাদেশ ইউরোপের একটি দেশ।»

এই Proposition-এর Truth Value হলো:

False

Truth Value যুক্তিবিদ্যার একটি মৌলিক ধারণা। Proposition, Logical Connective, Truth Table, Tautology, Contradiction, Validity এবং Logical Consequence বিশ্লেষণে এটি গুরুত্বপূর্ণ ভূমিকা পালন করে।

আধুনিক Logic-এ Truth Value-এর ধারণা Gottlob Frege-এর কাজের মাধ্যমে বিশেষভাবে গুরুত্বপূর্ণ হয়ে ওঠে। Frege Classical Logic-এ True এবং False-কে দুটি মৌলিক Truth Value হিসেবে বিবেচনা করেছিলেন। পরবর্তী সময়ে অনেক-valued logic-এর মতো বিভিন্ন Logical System-এ দুইটির বেশি Logical Value ব্যবহারের পদ্ধতিও বিকশিত হয়েছে।

সত্যমূল্যের ধারণা

Truth Value কোনো Proposition-এর Logical Status নির্দেশ করে।

Classical Logic-এ:

- True = সত্য
- False = মিথ্যা

ধরা যাক:

P = «ঢাকা বাংলাদেশের রাজধানী।»

তাহলে:

P = True

আর:

Q = «চট্টগ্রাম বাংলাদেশের রাজধানী।»

তাহলে:

Q = False

---

সত্যমূল্যের সংজ্ঞা

Truth Value হলো কোনো Proposition, Sentence বা Logical Expression-এর এমন Semantic Value যা নির্দেশ করে সেটি সত্য নাকি মিথ্যা।

Classical Propositional Logic-এ Truth Value-এর সেট সাধারণত:

{True, False}

অথবা:

{T, F}

দিয়ে প্রকাশ করা হয়।

Truth Value-এর ধারণা Logic-এর Semantic Analysis-এর একটি গুরুত্বপূর্ণ অংশ।

---

Truth ও Truth Value-এর পার্থক্য

Truth এবং Truth Value একই বিষয় নয়।

Truth হলো সত্য হওয়ার বৈশিষ্ট্য বা ধারণা।

Truth Value হলো কোনো নির্দিষ্ট Proposition-এর জন্য নির্ধারিত Logical Value।

উদাহরণ:

P = «২ + ২ = ৪»

এখানে:

- Truth = বক্তব্যটির সত্যতা
- Truth Value = True

---

Proposition ও Truth Value

Proposition হলো এমন একটি অর্থপূর্ণ ঘোষণামূলক বক্তব্য যাকে সত্য বা মিথ্যা হিসেবে মূল্যায়ন করা যায়।

উদাহরণ:

«পৃথিবী সূর্যের চারদিকে ঘোরে।»

এটি একটি Proposition।

এর Truth Value:

True

---

True

True হলো এমন Truth Value যা নির্দেশ করে সংশ্লিষ্ট Proposition সত্য।

প্রতীক:

T

অথবা:

⊤

উদাহরণ:

P = ২ + ২ = ৪

তাহলে:

P = T

---

False

False হলো এমন Truth Value যা নির্দেশ করে সংশ্লিষ্ট Proposition মিথ্যা।

প্রতীক:

F

অথবা:

⊥

উদাহরণ:

P = ২ + ২ = ৫

তাহলে:

P = F

---

Classical Logic

Classical Logic-এ সাধারণত দুটি Truth Value ব্যবহৃত হয়:

- True
- False

এই দুই-valued পদ্ধতিকে সাধারণভাবে Bivalent Logic বা Two-Valued Logic বলা হয়।

---

Principle of Bivalence

Principle of Bivalence অনুযায়ী কোনো নির্দিষ্ট Proposition-এর Truth Value সাধারণত True অথবা False—এই দুইটির একটি।

প্রতীকীভাবে:

P ∈ {T, F}

Classical Logic-এর অনেক Formal System এই দুই-valued Semantic Framework ব্যবহার করে।

---

Truth Assignment

Truth Assignment হলো Atomic Proposition-গুলোর জন্য Truth Value নির্ধারণ করা।

ধরা যাক:

P = বৃষ্টি হচ্ছে।

Q = রাস্তা ভেজা।

একটি Truth Assignment হতে পারে:

P = T

Q = F

অর্থাৎ:

বৃষ্টি হচ্ছে — সত্য।

রাস্তা ভেজা — মিথ্যা।

---

Valuation

Logic-এ Valuation হলো একটি Formal পদ্ধতি যার মাধ্যমে Logical Expressions-এর Truth Value নির্ধারণ করা হয়।

একটি Propositional Language-এর প্রতিটি Atomic Proposition-কে Truth Value দেওয়া হলে Compound Proposition-এর Truth Value Logical Connective-এর নিয়ম অনুসারে নির্ধারণ করা যায়।

---

Logical Connective ও Truth Value

Logical Connective এক বা একাধিক Proposition-এর Truth Value-এর ওপর ভিত্তি করে নতুন Logical Expression-এর Truth Value নির্ধারণ করে।

প্রধান Connective:

- Negation — ¬
- Conjunction — ∧
- Disjunction — ∨
- Conditional — →
- Biconditional — ↔

---

Negation

Negation কোনো Proposition-এর Truth Value উল্টে দেয়।

প্রতীক:

¬P

যদি:

P = T

তাহলে:

¬P = F

আর:

P = F

হলে:

¬P = T

---

Conjunction

Conjunction-এর প্রতীক:

P ∧ Q

Classical Logic-এ P ∧ Q তখনই True হয় যখন P এবং Q উভয়ই True।

Truth Table:

P| Q| P ∧ Q
T| T| T
T| F| F
F| T| F
F| F| F

---

Disjunction

Disjunction-এর প্রতীক:

P ∨ Q

Classical Inclusive OR-এ P ∨ Q False হয় কেবল তখন যখন P এবং Q উভয়ই False।

P| Q| P ∨ Q
T| T| T
T| F| T
F| T| T
F| F| F

---

Conditional

Conditional-এর প্রতীক:

P → Q

Classical Material Implication-এ এটি False হয় যখন:

P = T

এবং:

Q = F

Truth Table:

P| Q| P → Q
T| T| T
T| F| F
F| T| T
F| F| T

---

Biconditional

Biconditional-এর প্রতীক:

P ↔ Q

এটি True হয় যখন P এবং Q-এর Truth Value একই।

P| Q| P ↔ Q
T| T| T
T| F| F
F| T| F
F| F| T

---

Truth Table

Truth Table হলো একটি সারণি যার মাধ্যমে বিভিন্ন Truth Assignment-এর অধীনে Logical Expression-এর Truth Value দেখানো হয়।

উদাহরণ:

P ∧ Q

P| Q| P ∧ Q
T| T| T
T| F| F
F| T| F
F| F| F

Truth Table Propositional Logic-এর Semantic Analysis-এর একটি গুরুত্বপূর্ণ পদ্ধতি।

---

Tautology

Tautology হলো এমন Logical Expression যা সব সম্ভাব্য Truth Assignment-এর অধীনেই True।

উদাহরণ:

P ∨ ¬P

Truth Table:

P| ¬P| P ∨ ¬P
T| F| T
F| T| T

তাই:

P ∨ ¬P

একটি Tautology।

---

Contradiction

Contradiction হলো এমন Logical Expression যা সব সম্ভাব্য Truth Assignment-এর অধীনেই False।

উদাহরণ:

P ∧ ¬P

P| ¬P| P ∧ ¬P
T| F| F
F| T| F

তাই:

P ∧ ¬P

একটি Contradiction।

---

Contingency

Contingency হলো এমন Logical Expression যা কিছু Truth Assignment-এর অধীনে True এবং কিছু Truth Assignment-এর অধীনে False।

অর্থাৎ এটি:

- Tautology নয়
- Contradiction নয়

---

Logical Truth

Logical Truth হলো এমন Truth যা কোনো Logical Structure বা Logical Form-এর কারণে সত্য।

উদাহরণ:

P ∨ ¬P

Classical Logic-এ এটি একটি Logical Truth এবং Tautology।

Logical Truth-এর বৈশিষ্ট্য ও প্রকৃতি নিয়ে Logic ও Philosophy-তে বিভিন্ন তাত্ত্বিক আলোচনা রয়েছে।

---

Truth Value ও Validity

Truth Value কোনো Proposition-এর বৈশিষ্ট্য।

Validity কোনো Argument-এর বৈশিষ্ট্য।

একটি Argument Valid কিনা তা নির্ধারণে দেখা হয় এমন কোনো সম্ভাব্য পরিস্থিতি আছে কি না যেখানে:

- সব Premise True
- কিন্তু Conclusion False

যদি এমন কোনো পরিস্থিতি না থাকে, Argument Valid।

---

Truth Value ও Soundness

Sound Argument-এর জন্য:

1. Argument Valid হতে হবে।
2. সব Premise সত্য হতে হবে।

অতএব:

Soundness = Validity + True Premises

Truth Value এখানে Premise-এর সত্যতা যাচাইয়ে গুরুত্বপূর্ণ।

---

Truth Value ও Logical Consequence

Logical Consequence-এর ক্ষেত্রে দেখা হয় Premise-গুলোর Truth Value এমন কোনো অবস্থায় আছে কি না যেখানে সব Premise True কিন্তু Conclusion False।

যদি এমন কোনো Valuation না থাকে, তাহলে:

P₁, P₂ ⊨ C

অর্থাৎ C হলো P₁ ও P₂-এর Logical Consequence।

---

Truth Value ও Logical Equivalence

দুটি Logical Expression-এর Truth Value যদি প্রতিটি সম্ভাব্য Truth Assignment-এর অধীনে একই হয়, তাহলে তাদের Logical Equivalence থাকতে পারে।

উদাহরণ:

¬(P ∧ Q)

এবং:

¬P ∨ ¬Q

Classical Propositional Logic-এ এগুলো De Morgan's Law অনুযায়ী logically equivalent।

---

Atomic Proposition

Atomic Proposition হলো এমন Proposition যা সংশ্লিষ্ট Propositional System-এ আরও ছোট Logical Proposition-এ বিভক্ত করা হয় না।

উদাহরণ:

P = আজ সোমবার।

P-এর Truth Value হতে পারে:

T অথবা F।

---

Compound Proposition

একাধিক Proposition এবং Logical Connective ব্যবহার করে Compound Proposition তৈরি হয়।

উদাহরণ:

P ∧ Q

এখানে P এবং Q দুটি Atomic Proposition এবং ∧ হলো Logical Connective।

---

Propositional Logic

Propositional Logic-এ Proposition-কে সাধারণত P, Q, R ইত্যাদি Symbol দিয়ে প্রকাশ করা হয়।

প্রতিটি Proposition-এর Truth Value নির্ধারণ করা যায়।

উদাহরণ:

P = বৃষ্টি হচ্ছে।

Q = রাস্তা ভেজা।

তাহলে:

P → Q

একটি Compound Proposition।

---

Predicate Logic

Predicate Logic-এ Truth Value নির্ধারণের জন্য শুধু Proposition নয়, Domain, Variable, Predicate এবং Interpretation গুরুত্বপূর্ণ।

উদাহরণ:

Human(Socrates)

এই Formula-এর Truth Value নির্ভর করবে নির্দিষ্ট Interpretation-এর ওপর।

---

Truth Value ও Quantifier

Predicate Logic-এ Quantifier ব্যবহারের মাধ্যমে কোনো Domain-এর সদস্যদের সম্পর্কে বক্তব্য তৈরি করা হয়।

উদাহরণ:

∀x(Human(x) → Mortal(x))

এখানে Formula-এর Truth Value নির্ধারণের জন্য Domain এবং Predicate-এর Interpretation গুরুত্বপূর্ণ।

---

Truth Value ও Logical Form

Logical Form হলো কোনো Argument বা Expression-এর বিমূর্ত Logical Pattern।

উদাহরণ:

P → Q
P
∴ Q

এই Argument Form-এর Validity Truth Value-এর সম্ভাব্য Assignment বিশ্লেষণের মাধ্যমে পরীক্ষা করা যেতে পারে।

---

Truth Value ও Logical Structure

Logical Structure দেখায় একটি Logical Expression বা Argument-এর বিভিন্ন অংশ কীভাবে পরস্পরের সঙ্গে সম্পর্কিত।

উদাহরণ:

P ∧ Q

এখানে:

- P = প্রথম Proposition
- Q = দ্বিতীয় Proposition
- ∧ = Conjunction

Truth Value নির্ধারণে এই Structure গুরুত্বপূর্ণ।

---

Truth Value ও Inference

Valid Inference-এর একটি গুরুত্বপূর্ণ বৈশিষ্ট্য হলো Premise-এর Truth Conclusion-এর দিকে সংরক্ষিত থাকে।

উদাহরণ:

P → Q
P
∴ Q

যদি P → Q এবং P উভয়ই True হয়, তাহলে Q True হতে হবে।

এই Truth-Preservation ধারণাটি Valid Inference বোঝার ক্ষেত্রে গুরুত্বপূর্ণ।

---

Truth Value ও Argument

একটি Argument-এর প্রতিটি Proposition-এর নিজস্ব Truth Value থাকতে পারে।

উদাহরণ:

P₁ = True

P₂ = True

C = True

কিন্তু শুধু সব Proposition True হলেই Argument Valid প্রমাণিত হয় না।

Argument-এর Logical Structure-ও পরীক্ষা করতে হয়।

---

Truth Value ও Premise

Premise:

«সকল মানুষ মরণশীল।»

এর Truth Value নির্ধারণের প্রশ্নটি Argument-এর Validity থেকে আলাদা।

একটি Argument Sound হতে হলে Premise-গুলোর সত্যতাও নিশ্চিত হওয়া প্রয়োজন।

Frege ও Truth Value

Gottlob Frege আধুনিক Logic ও Semantics-এ Truth Value ধারণাকে কেন্দ্রীয় গুরুত্ব দেন। তাঁর বিশ্লেষণে Declarative Sentence একটি Truth Value নির্দেশ করতে পারে এবং Classical Framework-এ True ও False দুটি Truth Value হিসেবে ব্যবহৃত হয়।

Frege-এর কাজ পরবর্তী Formal Logic এবং Semantic Theory-এর বিকাশে গুরুত্বপূর্ণ প্রভাব ফেলেছে।

---

Two-Valued Logic

Two-Valued Logic-এ Truth Value-এর সংখ্যা দুটি:

- T
- F

এটি Classical Propositional Logic-এর পরিচিত কাঠামো।

---

Many-Valued Logic

Many-Valued Logic-এ দুইটির বেশি Logical Value ব্যবহার করা হতে পারে।

উদাহরণ:

- True
- False
- Intermediate বা অন্য কোনো Logical Value

Łukasiewicz এবং Emil Post-এর কাজ Many-Valued Logic-এর বিকাশে গুরুত্বপূর্ণ ছিল।

Many-Valued Logic-এর উদ্দেশ্য Classical Bivalence-এর বাইরে বিভিন্ন Semantic System তৈরি করা।

---

Three-Valued Logic

Three-Valued Logic-এ তিনটি Logical Value থাকতে পারে।

একটি উদাহরণ:

- True
- False
- Unknown

তবে বিভিন্ন Three-Valued Logic-এ তৃতীয় Value-এর অর্থ ও Logical Rules এক নয়।

তাই কোনো Three-Valued System ব্যবহারের আগে তার নির্দিষ্ট Semantic Rules জানা দরকার।

---

Fuzzy Logic ও Truth Degree

Fuzzy Logic-এ Classical True/False-এর পরিবর্তে Degree of Truth ব্যবহার করা যেতে পারে।

উদাহরণ:

Truth Degree = 0.7

এটি সাধারণ Classical Truth Value-এর মতো শুধু True বা False নয়।

Fuzzy Logic-এ Degree of Truth এবং Classical Truth Value একই ধারণা নয়।

সম্পূর্ণ উদাহরণ

ধরা যাক:

P = বৃষ্টি হচ্ছে।

Q = রাস্তা ভেজা।

তাহলে:

P-এর Truth Value

যদি বৃষ্টি সত্যিই হয়:

P = T

¬P

যদি P = T হয়:

¬P = F

P ∧ Q

P এবং Q উভয় True হলে:

P ∧ Q = T

P ∨ Q

P অথবা Q-এর অন্তত একটি True হলে:

P ∨ Q = T

P → Q

P True এবং Q False হলে:

P → Q = F

অন্য ক্ষেত্রে Classical Material Implication অনুযায়ী এটি True।

---

Truth Table উদাহরণ

ধরা যাক:

P = আজ বৃষ্টি হচ্ছে।

Q = রাস্তা ভেজা।

Compound Expression:

(P ∧ Q) → Q

Truth Table:

P| Q| P ∧ Q| (P ∧ Q) → Q
T| T| T| T
T| F| F| T
F| T| F| T
F| F| F| T

তাই:

(P ∧ Q) → Q

Classical Propositional Logic-এ একটি Tautology।

উপসংহার

সত্যমূল্য (Truth Value) হলো কোনো Proposition বা Logical Expression সত্য নাকি মিথ্যা—তা নির্দেশকারী মৌলিক Logical Value।

Classical Logic-এ সাধারণত দুটি Truth Value ব্যবহৃত হয়:

True (T)
False (F)

Truth Value-এর মাধ্যমে Proposition বিশ্লেষণ করা যায় এবং Logical Connective-এর মাধ্যমে Compound Proposition-এর Truth Value নির্ধারণ করা যায়।

Truth Table ব্যবহার করে কোনো Logical Expression-এর সম্ভাব্য সব Truth Assignment পরীক্ষা করা যায়। এর মাধ্যমে Tautology, Contradiction এবং Contingency শনাক্ত করা সম্ভব।

Truth Value Validity, Soundness এবং Logical Consequence-এর সঙ্গেও ঘনিষ্ঠভাবে সম্পর্কিত। Valid Argument-এর ক্ষেত্রে এমন কোনো Truth Assignment থাকা উচিত নয় যেখানে সব Premise True কিন্তু Conclusion False।

Frege-এর কাজের মাধ্যমে Truth Value আধুনিক Logic ও Semantics-এর একটি কেন্দ্রীয় ধারণায় পরিণত হয়। পরবর্তীতে Classical Two-Valued Logic-এর পাশাপাশি Many-Valued Logic এবং অন্যান্য Semantic System বিকশিত হয়েছে।

Mathematics, Computer Science, Boolean Logic, Programming, Database, Artificial Intelligence, Automated Reasoning এবং Formal Verification-এর মতো ক্ষেত্রেও Truth Value-এর ধারণা গুরুত্বপূর্ণ।

অতএব, যুক্তিবিদ্যা শেখার ক্ষেত্রে Proposition-এর পর Truth Value একটি মৌলিক ধারণা। Truth Value ভালোভাবে বোঝা গেলে Truth Table, Logical Connective, Tautology, Contradiction, Validity এবং Logical Consequence-এর মতো পরবর্তী ধারণাগুলো বোঝা সহজ হয়।
